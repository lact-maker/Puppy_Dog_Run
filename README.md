# 小狗双人跑酷 · 原型 0.5.0

安卓横屏双人合作跑酷。小鸡毛（浅杏色）与小白（白色）按照用户提供的线条小狗参考图生成透明逐帧素材，并以动作帧切换实现动画。

## 立即体验

- 安装包：`artifacts/小狗双人跑酷-0.5.0.apk`。这是调试签名的测试包，支持 Android 8.0+，需要较新的 Android System WebView。
- 单人模式和双人模式均需连接服务器，由服务器模拟、上榜、发放金币。单人模式一人操作跳跃和冲刺两个按钮。
- 大厅较长时可向上滑动。选择小鸡毛或小白后点击“进入单人模式”。
- 电脑浏览器可访问 `http://localhost:8787`；空格跳跃，D / → 冲刺，Esc 暂停。

## 两台手机联机

1. 在电脑项目目录运行 `node server/index.mjs`，或执行 `scripts/start-server.ps1`。
2. 两台手机和电脑连接同一 Wi-Fi。查找电脑的局域网 IPv4 地址（例如 `192.168.1.10`）。
3. 两台手机点击右上角连接状态，均填写 `http://电脑IP:8787`。不要填写 `localhost`，它在手机上指手机自己。
4. 一方创建房间，复制邀请文字通过微信自行发给搭档；另一方输入 6 位房间码。
5. 房主选择角色、设置队名、交换职责。双方准备后由房主开始。一台手机仅显示跳跃，另一台仅显示冲刺。

电脑须持续开机并运行服务。Windows 防火墙如拦截，需允许 Node.js 在专用网络接受连接。项目没有自动更改防火墙。

不同网络的手机需要同一个可访问的公网服务器。项目已包含服务端及 Dockerfile，但**没有替你购买、配置或部署公网主机**。公网部署应使用 HTTPS/WSS 反向代理和持久化 `data` 目录，客户端填写该服务器的 HTTPS 根地址。此原型的文件存储适用于单实例、小规模测试，不适用于直接大规模公开运营。

## 本轮外观与动作

采用基于用户参考图生成的 16 帧透明动作素材（public/assets/dog-sprites.png）：小白采用蓬松方形轮廓，小鸡毛采用垂耳、浅杏色和细红项圈。大厅互动、角色选项、侧栏、小队、排行榜、练习卡片均有动态角色。恢复第一版大厅文案，保留上版两条简明玩法说明。

跳跃过程中仍按当前跑速持续前进，垂直方向受重力影响；二段跳只刷新向上的速度。镜头前移变化限制为角色水平位移的 4%，地形滚动维持正常速度的 96%～104%，避免起跳时环境减速和落地时突变。平地增加草纹以显示滚动。

## 单人榜、金币与衣橱

- 单人开局可修改个人昵称；头像与昵称用于单人排行榜。单人和双人榜各显示前 20 名，每个玩家/队伍保留最佳一局的总里程与同局用时。
- 消灭每只怪物增加 5 米奖励里程，冲刺与宝剑均有效。总里程 = 实跑里程 + 击杀奖励；奖励不让角色位置瞬移。
- 每局总里程每满 5000 米到账 1 金币，不足部分不跨局累计。途中跨过阈值立即保存；结算补齐差额。同一局重连/重试不重复发放。
- 单人记入本人账户；双人仅记入开局房主账户，不受交换按钮职责或结束后的房主转移影响。
- 帽子 10、鞋 25、上衣 100、裤子 100 金币，购买永久保存，可免费穿脱，两只角色共用账户的装饰。首次购买自动穿上，开局固定该局穿搭；双人使用房主穿搭。装饰不改变能力。
- 余额、永久拥有列表、穿搭和发奖记录存入服务器 data/store.json，重启后保留。原有双人队伍和成绩兼容保留，旧版练习成绩不补录入榜或追发金币。
- 与原型身份一致：同一手机、同一服务器的身份保留。卸载应用/清除数据后尚无账号找回；这里的“永久”是该游戏账户的所有权。

## 声音

游戏左上角 ♫ 开关统一控制背景音乐与音效，静音偏好保存在本机。开局后播放、暂停和后台停止，返回大厅不自动播放。跳跃、冲刺、道具、受伤和结束有不同音效。

当前背景音乐为程序合成的临时原创轻音乐，**尚未包含《鸡毛之歌》**。收到用户提供的具体音频后，把文件放到 public/assets/ 并配置 public/audio.mjs 中 BACKGROUND_TRACK.url，再重新打包。MP3/OGG/WAV 类型支持已接入。

网页和安卓桌面图标均采用 public/assets/duo-icon.png，安卓使用自适应图标遮罩。

## 已实现的规则

- 六条隐形基准线分成五层，只绘制实际地面和线状台阶。第一层随机断崖，第二至第四层随机单向台阶，第五层固定向下延伸一层的尖刺。
- 每段跳跃最高一层，二段跳累计最高两层；落到地面或台阶恢复次数。台阶只承接下落，侧面和底部不阻挡、不伤害。
- 两次空中冲刺，落地恢复；地面冲刺冷却 1 秒。每次冲刺 0.3 秒、连续触发间隔 0.15 秒、速度为基础跑速的 2 倍。
- 正常跑跳直立，冲刺低伏四足跑。冲刺动画不缩小碰撞范围。
- 基础跑速每 100 米增加初始跑速的 10%，平滑递增，上限 4 倍；冲刺可短暂达到初始跑速的 8 倍。
- 怪物在五层悬空向左移动，速度为当前基础跑速的 25%，不随冲刺翻倍；遇尖刺用 0.2 秒下降一层。
- 宝剑约每 500 米出现一次（相邻间距 400–600 米），爱心约每 1000 米出现一次（相邻间距 800–1200 米）；初次分别在 450–550 米和 900–1100 米。位置由种子与里程决定，联机双方一致。
- 宝剑和爱心可在五层生成，其动画及拾取范围不与尖刺重合。宝剑免疫怪物和尖刺 10 秒，重复拾取刷新；冲刺只免疫怪物。爱心加命，上限 3。
- 初始 1 条命，受伤有 1.5 秒保护；掉出底部死亡边界直接结束。随机生成允许出现必死组合，不提供可通行保证。
- 任一方暂停全局，双方确认并倒数 3 秒后继续。服务器检测到掉线后等待 15 秒，成功重连继续；超时或主动退出按已确认成绩标记中断。
- 相同两人恢复历史队伍、队名、主角和成绩；不同搭档分别保存。房主变更角色或队名清除双方准备状态。
- 双人榜展示双方头像、队名、最佳总里程与该局实际游玩时间（排除暂停、倒数及等待）。每队一条，同分先到者优先。中断局也可更新最佳成绩。

## 头像与身份

头像由用户上传，在客户端裁切压缩至 192×192 后保存，支持 PNG/JPEG/WebP。不接入微信登录、头像授权、支付或好友系统。

联网身份由服务器随机生成，客户端保存不透明凭证。同一服务器上的身份保留，换服务器会使用另一份身份。卸载 App、清空浏览器数据或丢失服务器数据后暂不能恢复原身份。

## 开发与构建

需要 Node.js 22+。依赖已安装；换环境时运行 `pnpm install --frozen-lockfile`，也可使用 npm 安装 package.json 中锁定的直接依赖。

```powershell
node --test tests/*.test.mjs
node server/index.mjs
node scripts/sync-android.mjs
./scripts/build-android.ps1
```

`build-android.ps1` 默认复用 `C:\Users\ll\Documents\Codex\2026-09-29\new-chat\work` 内的 JDK 17、Gradle 8.13、Android SDK 36 和缓存；可通过 `-ToolRoot` 指向同结构目录。离线构建输出 APK 到 `artifacts`。也可用 Android Studio 打开 `android` 目录，先同步网页资源，再构建。

目录：

- `public/game.mjs`：浏览器练习和服务器共用的确定性游戏模拟。
- `public/art.mjs`：角色帧动画、服装叠加及赛道 Canvas 绘制。
- `public/shop.mjs`：服装目录、固定售价。
- `public/app.mjs`、`index.html`、`style.css`：页面、资料、联机客户端和操作。
- `server/`：HTTP、WebSocket、房间状态机、身份和原子文件保存。
- `android/`：原生安卓 WebView 容器，应用资源随 APK 打包，支持图片选择。
- `tests/`：规则、随机生成、持久化、重连和真实双客户端网络测试。

环境变量：`PORT`（默认 8787）、`DATA_FILE`（默认 `data/store.json`）。数据文件含玩家凭证哈希，不应发布或提交版本库。运行中房间存在内存中，正常停止会结算正在进行的对局，强制结束进程可能丢失尚未结算的那一局。

## 交付边界

已提供可安装安卓原型和可自运行的联机服务器。调试 APK 不等于商店上架包；尚未进行真实双手机公网弱网测试。正式上线前仍需账号恢复、内容审核、防滥用、监控、HTTPS 服务及发行签名。

## 0.6 黑洞与本局道具
- 按包含击杀奖励的总里程，达到 300、5300、10300、15300…米时，各生成一个黑洞。黑洞在前方随机位置、第一至第四层出现，碰到后进入商店；错过不会补发。
- 三枚金蛋分别藏着秒表、浮桥、护身符，位置由服务器随机打乱，每次免费敲一枚。双人由冲刺方选择，单人由本人选择。选完点击继续，倒数 3 秒恢复；商店和倒数不计游玩时间。
- 道具在本局有效，重复获得次数叠加，下局清空。秒表、浮桥仅冲刺方显示使用按钮；单人显示全部按钮。
- 秒表消耗一次，怪物的移动、降层和振翅暂停 5 秒，角色及场景继续移动，怪物仍有碰撞。再次使用刷新到 5 秒，游戏暂停不消耗时长。
- 浮桥消耗一次，在脚下生成三段向前下降的台阶浮桥，立即站稳，恢复两次跳跃和两次空中冲刺，并清除冲刺冷却；桥随场景滚动移出。
- 护身符仅掉崖时自动消耗，原地上移到安全浮桥并恢复动作次数，保留里程和生命，短暂无敌；不会抵挡怪物或尖刺造成的致命伤害。
- 商店掉线同样等待 15 秒，重连回到原商店和已选奖励；超时或退出按中断结算。


## 0.7.0 手机流畅度优化（2026-10-01）
- 黑洞间隔更新为 800 米：300、1100、1900、2700…米。每 5000 米 1 金币的规则不变。
- 手机按下跳跃、冲刺后立即预测动作，服务器以输入序号确认，再平滑校正；本地预测不提交成绩或金币。网络短时抖动可补帧至 250 毫秒，长时间无状态则停止预测，避免无限跑偏。
- 双人共享角色：本机按钮可立即预测，搭档按钮仍需网络传递。跨地区延迟和服务器长时间停顿无法仅靠客户端彻底消除。
- 新客户端协商增量状态：不重复发送未变地形和道具；重连发送完整基线。慢连接跳过过期状态，保留后续纠正。
- 游戏画布像素倍率上限由 2 降至 1.25；状态文字刷新为每秒 10 次；物理子步复用地形列表，减少分配。
- 手机 APK 和服务器必须一起更新到 0.7.0。旧服务器不支持预测确认时自动退回服务器响应模式，黑洞周期也仍由旧服务器决定。
- 本地自动测试与构建不代表实际手机帧率；远程服务器本次未部署。


## 0.8.0 六种金蛋道具（2026-10-01）
每次从秒表、浮桥、护身符、火焰球、小小狗、天使之翼中随机抽取三种不同道具，打乱后藏入三枚金蛋，仍只选一枚。奖励由服务器发放并防止重复领取。
- 火焰球：获得即增加 5 秒自动发射时长，恢复游戏后向前连续发射；每次击杀仍加 5 米。剩余时长叠加，商店/暂停不扣时间，结束后火球消失。不会抵挡尖刺。
- 小小狗：自动跟随，使用与主角相反的角色外观；提供独立于最多 3 颗爱心之外的一次护命机会。主角受到一次未被宝剑/冲刺免疫的怪物或尖刺伤害时，小小狗消失，爱心不减；再次受伤正常扣心。有伙伴时再获得不叠加；不能救掉崖（掉崖由护身符负责）。
- 天使之翼：库存按次数叠加。双人仅跳跃方显示按钮，单人可直接使用。消耗一次飞行 10 秒，生效期间按钮禁用，保留其余次数；长按跳跃向上，松开向下，升降均固定 180 世界单位/秒（两层/秒），前进仍按当前跑速计算。飞行不消耗二段跳次数，下降能落在地面/台阶；有顶部边界，仍会撞尖刺或怪物。到期恢复重力和普通跳跃。
暂停、断线、进入商店和重新倒数均清除长按状态，继续游戏后需要重新按住。触摸取消和失去焦点也会释放按键。道具仍限本局，下一局清空。
安卓和服务端均需更新至 0.8.0；远程服务未在此轮部署。
